# Security policy

GitHub private vulnerability reporting is enabled for this repository. Use its
**Report a vulnerability** control for private reports. Do not publish
proof-of-concept content, private notes, vault paths, access tokens, or other
sensitive data in a public issue.

The minimal baseline also enables Dependabot alerts/security updates, secret
scanning, and push protection. GitHub currently reports no code-scanning
analysis for this CSS/shell repository; the repository CI verifies the build but
does not claim CodeQL coverage. This repository intentionally does not publish
a personal email address.
